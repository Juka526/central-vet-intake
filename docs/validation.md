# 검증 결과

2026-11-23, macOS·Node.js 26.13.1에서 가상 데이터만으로 검증했습니다. 실제 환자, 실제 마이크 녹음, 외부 AI, 인투벳 GE에 접속하지 않았습니다.

## 자동 검증

`npm run check`로 서버·문진 엔진·브라우저 코드의 문법을 확인했습니다. `npm test`의 26개 테스트가 통과했습니다. 최종 반복에서 드러난 대용량 요청 거부 직후 연결 초기화 문제는 서버가 초과 본문을 메모리에 보관하지 않고 끝까지 소비하도록 수정했으며, 해당 연결 회귀 검사를 추가하고 관련 검사를 3회 반복해 통과했습니다.

- 증상 10종·초진/재진·복합 증상에서 질문 5~10개 상한과 중복 방지, 후속 답변 기반 질문 추가.
- 직접 선택·불확실·키워드 후보의 구분, 주호소/답변에서 위험 후보 표시, 부정·과거 표현을 안전 판정으로 바꾸지 않음.
- 원문 기반 초안, “모름” 보존, O/A/P·진단·처방 미생성.
- 필수/선택 동의·동의 버전·가상정보·최종 확인, 누락 답변과 길이·식별정보·음성 헤더 검증.
- 비인증·CSRF·외부 Origin 차단, 보호자/접수 담당자의 원문·음성·승인·복사·감사 접근 제한.
- 위조된 승인·요약 무시, 원문 확인·위험 확인 없는 승인 차단, 미검토 보류 허용, 동시 수정과 오래된 승인본 복사 차단.
- 기본 원본 미저장, 동의 없는 업로드 차단, 수의사 음성 접근·삭제, 1시간 음성·24시간 문진 만료와 세션 만료.
- 자료삭제 후 접근 차단, 감사로그에 원문·접근 코드 미포함, JSON·대용량 오류 처리와 거부 직후 연결 재사용, 보안 헤더·정적 파일 허용 목록, 로그인 세션 회전·로그아웃·실패 횟수 제한.

음성 API 테스트는 합성 바이트로 권한·보관·삭제를 확인합니다. 실제 음성 디코딩이나 한국어 인식 품질을 검증한 것은 아닙니다. 위험 표현 테스트는 공학적 회귀 테스트이며 임상적 민감도·특이도를 측정하지 않습니다.

## 브라우저 확인

보호자 필수 동의 → 예시 주호소 → 후속 답변 → 위험 체크 → 제출 → 수의사 로그인 → 원문/초안 확인 → 미검토 보류 → 두 문서 확인 → 승인 → HPI 복사를 실제 UI에서 수행했습니다. 승인 전 복사 잠금과 보류 유지도 확인했습니다.

CSS 화면 폭 390px(휴대폰), 820px(태블릿), 1200px(데스크톱)에서 화면 구성을 확인했습니다. 390px과 820px에서 전체 문서의 가로 넘침이 없는 것을 확인했고, 모바일 크기에서 재진·배뇨 위험 문진 제출과 연락 안내도 확인했습니다. 작은 폭 325px에서도 첫 화면의 가로 넘침이 없었습니다. 이는 브라우저 크기 검증이며 실제 기기 검증이 아닙니다.

의료진 공간에서 새로고침 버튼을 눌러도 작성 중 검토 메모가 유지되는 것을 확인했습니다. 수의사 세션에서 브라우저를 새로고침하면 접수함으로 돌아가고, 보호자 화면으로 이동하면 의료진 세션이 종료됩니다. 시험 중 브라우저가 수집한 오류·경고 로그는 없었습니다.

## 미검증·남은 한계

실제 모바일/태블릿 하드웨어, 마이크 권한, 한국어 로컬 인식, 약명·수치·부정어 인식률, 네트워크 단절과 장시간 부하, OS 메모리 보관, 보조기술 사용성 전반, 임상 누락률, 법률·보안 운영 적합성, 공식 EMR 연동은 검증하지 않았습니다. 기록 삭제가 OS 스왑이나 사용자가 복사한 클립보드까지 제거하지는 않습니다. 이 한계는 [서비스 준비 계획](production-gates.md)에 따라 별도로 해소해야 합니다.
