# 센트럴 문진 · AI 수의 음성 문진 MVP

전주 센트럴 동물메디컬센터의 **가상 환자 내부 시험용** 웹앱입니다. 보호자가 내원 전에 증상을 이야기하거나 입력하고, 수의사가 원문과 HPI·SOAP Subjective 초안을 대조해 수정·승인·보류합니다. 진료실 녹취, 진단·처방, EMR 대체 기능은 없습니다.

## 실행

Node.js 22.13 이상이 필요합니다. 별도 패키지 설치, 모델 키, 외부 서비스 가입은 필요하지 않습니다. `node:sqlite`가 포함된 최근 Node.js LTS를 권장합니다. 검증한 환경은 Node.js 26.13.1입니다.

전달받은 ZIP을 먼저 압축 해제하고, `central-vet-intake` 폴더에서 터미널을 열어 실행합니다. `package.json`과 `server.mjs`가 보이는 폴더인지 확인하세요.

```sh
npm start
```

[http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다. 실행 터미널에 표시되는 **수의사 코드 / 접수 코드**를 의료진 화면에 입력하세요. 기본 코드는 실행할 때마다 임의로 생성됩니다. 종료는 터미널에서 Ctrl+C입니다. macOS에서는 [start-demo.command](start-demo.command)를 실행해도 됩니다. 파일 실행이 차단되면 터미널에서 `npm start`를 사용하세요.

포트나 시험용 코드를 지정하려면 다음과 같이 실행합니다. 코드는 서로 다른 8자 이상이어야 합니다.

```sh
PORT=4318 VET_CODE='choose-a-vet-test-code' RECEPTION_CODE='choose-a-front-test-code' npm start
```

병원에서 확인한 대표번호가 있을 때만 `HOSPITAL_PHONE`을 추가하세요. 미설정 상태에서는 번호를 만들어 표시하지 않고 원내 직원 또는 이용하는 병원에 즉시 연락하도록 안내합니다.

앱은 **이 컴퓨터의 localhost에만** 접속할 수 있습니다. 화면은 휴대폰·태블릿·데스크톱 크기에 대응하지만, 현재 실행 주소로 다른 스마트폰이 직접 접속할 수는 없습니다. 원내 여러 기기나 원외 보호자가 함께 쓰려면 [실제 서비스 준비](docs/production-gates.md)를 먼저 진행해야 합니다. 포트 개방이나 공개 터널을 사용하지 마세요.

## 5분 시험

1. 보호자 화면에서 가상 환자 보리·나비·두부·레오 중 하나와 초진/재진을 선택합니다. 가상정보 사용 확인과 정보처리 필수 동의만 체크해도 텍스트 문진을 할 수 있습니다. 재진 이력은 가상 예시이며 인투벳 GE 조회가 아닙니다.
2. 주요 증상을 선택하고 **가상 예시 넣기** 또는 텍스트 입력을 사용합니다. 음성 선택 동의를 한 경우 지원 기기에서 음성 입력을 시도할 수 있습니다.
3. 후속 질문 7~10개에 답합니다. **가상 답변 채우기**도 가능합니다. 새 증상이 답변에 있으면 다음 단계로 넘어갈 때 질문이 추가될 수 있습니다. 모르면 “모름”, 해당하지 않으면 “없음”으로 적습니다.
4. 위험 징후 8개를 각각 예/아니요/모르겠어요로 확인하고 제출합니다. 모두 아니요는 응급 상태가 아니라는 뜻이 아닙니다. 위험 표현이나 불확실한 징후는 병원에 즉시 연락하도록 안내합니다.
5. 화면 위쪽 **의료진 공간** 또는 제출완료 화면의 **의료진 검토 시험**을 누르고 수의사 코드로 로그인합니다. 접수함에 방금 제출한 환자가 **검토 대기**로 나타나면 접수 성공입니다. 원문·문제목록·시간 흐름·약물·병력·누락정보·위험 후보를 대조합니다. HPI와 SOAP S를 각각 수정할 수 있습니다.
6. 접수 행의 **검토하기**를 누르세요. 원문 대조를 체크하지 않고 메모를 적어 **보류하기**를 시험합니다. 복사 버튼은 잠긴 상태입니다. 보류 상태는 목록의 **보류** 탭에서 다시 열 수 있습니다. 이후 원문과 두 문서를 확인하고 승인합니다. 목록이 **승인 완료**로 바뀌고 복사 버튼이 활성화되면 승인 성공입니다. 위험 후보가 있으면 추가 확인 체크도 필요합니다.
7. **HPI 복사 / SOAP S 복사**로 승인본만 복사합니다. 실제 EMR에는 시험 자료를 넣지 마세요. 승인 후 수정한 내용은 다시 승인해야 복사할 수 있습니다. 감사로그와 자료삭제도 시험할 수 있습니다. 보호자는 제출완료 화면의 **제출 자료 삭제**, 수의사는 검토창 아래 **이 가상 문진과 음성 삭제**를 누릅니다. 삭제 완료 안내가 표시되고 의료진 목록에서 사라지는지 확인하세요.

## 음성의 지원 범위

- 브라우저의 Web Speech API를 사용하며 `processLocally=true`를 지원할 때만 인식을 시작합니다. 한국어 로컬 모델이 준비되지 않았거나 인식·마이크 권한·브라우저 지원에 문제가 있으면 텍스트로 이어갑니다. 외부 음성인식으로 자동 전환하거나 모델을 자동 다운로드하지 않습니다. `processLocally=true`의 동작은 [MDN 문서](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally)를 기준으로 구현했습니다.
- 시험할 때는 첫 단계에서 음성 처리에 동의하고 **음성으로 이야기하기**를 눌러 지원 여부를 확인하세요. “기기 내 한국어 모델이 준비되지 않았습니다”라는 안내가 나오면 이 MVP에서는 텍스트로 진행합니다. 한국어 로컬 모델 제공·설치는 브라우저별로 달라 앱 안에서 설치를 안내하거나 외부 서비스 사용을 켜지 않습니다.
- **마이크로 실제 한국어를 인식하는 것은 이번 환경에서 검증하지 못했습니다.** Safari/iOS, Android, 원내 태블릿에서 각각 확인해야 합니다. 데모의 텍스트·문진·검토 흐름은 음성 없이 완결됩니다. 안정적인 전 기기 음성이 필요하면 병원이 관리하는 로컬 STT 또는 계약·보관정책을 검토한 STT 제공자 연동을 다음 단계로 진행하세요.
- 음성 처리 동의와 원본 보관 동의는 별도입니다. 원본 미보관이 기본입니다. 원본 보관을 선택한 경우에만 MediaRecorder를 사용하며, 마지막 60초 이하 녹음 한 개를 제출할 수 있습니다. 1MB 초과는 원본을 버리고 인식한 글만 유지합니다. **재녹음 시 이전 원본은 새 원본으로 대체**됩니다. 음성 보관 동의만으로 실제 음성 파일이 반드시 생성되는 것은 아닙니다.
- 선택 동의한 원본은 제출 후 서버 메모리에 최대 1시간만 보관합니다. 수의사만 재생할 수 있으며 보호자 제출완료 화면이나 수의사 화면에서 즉시 삭제할 수 있습니다. 시간 만료 후에는 재생할 수 없습니다. 클라이언트의 60초 제한과 별도로 서버는 파일 헤더·형식·1MB 크기를 검증하지만 녹음 시간을 디코딩해 검증하지 않습니다.

## 데이터와 접근 권한

| 대상 | 이 MVP의 처리 |
| --- | --- |
| 환자 | 고정된 가상 식별자 3개만 허용. 실제 이름·연락처 입력 필드 없음 |
| 문진·동의·검토 | 서버 내 메모리 SQLite. 제출 후 최대 24시간, 서버 재시작 시 전체 소멸 |
| 음성 원본 | 선택 동의 시에만 서버 메모리에 최대 1시간. 기본 미생성 |
| 감사로그 | 작업 시각·역할·임의 시험 식별자·문진 ID만 최대 24시간. 원문·음성·접근 코드 미포함 |
| 보호자 | 본인이 제출한 자료·음성의 삭제 가능. 접수 목록·의료진 원문·승인·복사 접근 불가 |
| 접수 담당자 | 가상 환자명·증상 분류·접수 시간·상태·위험 후보 수만 조회. 원문·병력·음성·승인·복사·로그 접근 불가 |
| 수의사 | 원문·초안·동의 확인, 수정·승인·보류, 승인본 복사, 음성 대조, 삭제, 로그 확인 |
| 브라우저 | localStorage·IndexedDB·서비스워커에 문진을 저장하지 않음. 새로고침 시 작성 중 내용 소멸. 15분 미사용 시 화면·세션 초기화 |

세션은 발급 후 1시간 만료됩니다. 보호자 직접 삭제는 제출한 브라우저 세션이 유지되는 동안 가능합니다. 의료진 로그인이나 새 세션 생성 후에는 수의사가 삭제해야 합니다. **의료진 로그인 시 보호자 작성 화면을 비우며, 보호자 화면으로 돌아가면 의료진 세션을 종료**합니다. 태블릿에서는 다음 보호자가 사용하기 전에 “새 문진 시작 · 화면 비우기”를 누르세요.

자동 삭제 작업은 1분마다 수행하고 요청 시에도 만료 여부를 확인합니다. 만료된 자료는 조회되지 않습니다. 앱은 디스크 파일을 만들지 않지만 OS 스왑·메모리 덤프·브라우저/운영체제의 자체 보관까지 삭제를 보장하지 않습니다. 원문 삭제 뒤 남는 감사 항목은 임의 ID만 포함하고 그 항목도 24시간 뒤 삭제됩니다.

서버에서 역할, 세션, CSRF, Origin·Host, 필수 동의, 최종 확인, 입력 길이·형식, 위험 체크, 승인 상태, 문서 버전을 검증합니다. 동시 검토 충돌은 저장을 거부합니다. 명백한 전화번호·이메일·주민번호 형태도 거부하지만, 자유서술의 개인정보를 모두 찾아낼 수는 없습니다. **가상정보 확인 체크는 익명화 보장이 아닙니다.**

현재 역할별 공유 코드는 데모 접근 제어입니다. 직원 본인 확인, 다중 병원 격리, 저장 암호화, 변경불가 감사 기록 또는 운영 인증 체계를 갖춘 제품이라는 뜻이 아닙니다.

## 문진·요약 엔진과 인투벳 GE

[lib/engine.mjs](lib/engine.mjs)는 증상 10개 분류와 공통 병력 질문, 주호소·후속 답변 기반 추가 질문을 정의합니다. 특정 질환 전용 엔진은 아닙니다. “기타 증상”도 받을 수 있으나 희귀 증상·타 동물종의 임상적 포괄성을 검증한 것은 아닙니다. 질문은 현재 최대 10개이며 별도의 위험 체크 8개는 이 수에 포함하지 않습니다.

현재 요약은 결정적 규칙으로 보호자 보고를 구조화합니다. 외부 LLM이나 키를 사용하지 않으며, 새 임상 사실을 추론하지 않습니다. 문제목록은 보호자의 주호소이고 확정 진단이 아닙니다. “모름”을 정상·없음으로 바꾸지 않습니다. 위험 키워드는 부정·과거 표현도 후보로 표시하므로 거짓 양성이 있을 수 있고, 표현 누락으로 거짓 음성도 있을 수 있습니다. 현재/과거, 부정, 복합 증상 해석은 수의사의 재확인이 필요합니다.

[lib/emr-adapter.mjs](lib/emr-adapter.mjs)가 EMR 경계입니다. `fetchHistory()`는 연결 불가를 반환하고 `formatApproved()`는 승인된 문서만 반환합니다. 인투벳 GE 공식 API의 권한·비용·기능은 미확정입니다. 무단 DB 접근, 화면 수집, EMR 파일 열람, 자동 쓰기 기능은 없습니다. 장기 연동은 계약과 시험 환경을 확보한 후 이 모듈을 교체하는 방식입니다.

## 코드와 검증

```text
server.mjs                 HTTP API · 세션 · 역할 · 메모리 SQLite · TTL · 감사
lib/engine.mjs             가상 환자 · 동의 버전 · 문진/위험/초안 규칙
lib/emr-adapter.mjs        공식 연동 경계 · 승인본 복사 형식
public/                   한국어 반응형 UI (외부 폰트·분석 스크립트 없음)
test/                     문진·안전·접근권한·삭제·동시검토 테스트
docs/production-gates.md   실제 서비스 전 필요한 검토와 다음 개발 순서
docs/validation.md         검증 결과와 확인하지 못한 범위
```

```sh
npm run check
npm test
```

테스트는 임시 localhost 포트와 별도 메모리 DB를 사용합니다. 실행 중인 앱의 문진에는 영향을 주지 않습니다. 망 연결 없이 실행되며 테스트 서버를 열 권한은 필요합니다.

## 다음 개발

우선 병원 수의사가 질문·위험 문구를 검토하고, 가상 시나리오에서 누락과 검토 부담을 평가합니다. 그다음 실제 기기의 한국어 음성과 태블릿 사용성을 확인합니다. 개인별 인증과 운영 데이터 관리, 법무·보안 검토를 마친 뒤 제한적인 실제 보호자 실증을 설계하세요. 구체적인 준비 항목은 [실제 서비스 준비와 개발 계획](docs/production-gates.md)에 있습니다.
